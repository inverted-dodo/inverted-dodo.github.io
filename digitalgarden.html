Tech Stack

  • Framework: Quartz
  • Hosting: GitHub Pages

Project Overview

A personal knowledge base and note-taking system built on top of Quartz. Notes are interconnected through bidirectional links, forming a growing garden of ideas.

Design Decisions

Needed a simple framework to publish notes as a static page without development overhead. Quartz provided bidirectional linking out of the box.
